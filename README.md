# DREFI-ShopManager-Updates

DR EFI 車行管理系統的自動更新檔案。

- `latest.json`：最新版本資訊（以 DR EFI 原廠金鑰簽章，程式會驗證簽章與檔案檢查碼，未經簽章的內容一律忽略）
- `updates/`：各版本的更新程式

已安裝的電腦會自動檢查這裡的 `latest.json`，有新版本時在畫面上方提示更新。

## 手動下載更新程式
已安裝過的電腦，也可以直接下載最新的更新程式執行：
[updates/DR-EFI-Update-1.6.6.exe](updates/DR-EFI-Update-1.6.6.exe)（點進去後按右上角的下載按鈕）

## 版本紀錄
- **1.6.6**（2026-11-24）自動更新測試版，功能與 1.6.5 相同
- **1.6.5**（2026-11-20）內建自動更新；工單明細與列印零件排在工資前；包含 1.6.1～1.6.4 所有修正
